Font assets for browser mockups
==============================

Downloaded from the Google Fonts repository:

- Roboto: https://github.com/google/fonts/tree/main/ofl/roboto
- Roboto Condensed: https://github.com/google/fonts/tree/main/ofl/robotocondensed
- Barlow: https://github.com/google/fonts/tree/main/ofl/barlow

Each family has its OFL license alongside its files. The mockup embeds these
fonts so that snapshots and server restarts do not depend on an external font CDN.

The picker option “Bionic-style · approximation” uses Barlow. It is a design
alternative, not Garmin's Bionic font or a verified match to Portal or Cluster.
