# Orbit native prototype

Build a Monkey C watch face for the fēnix 9 Pro 47 mm AMOLED (454 × 454) under `faces/orbit/connectiq/`. Use the brushed titanium browser mockup as the reference for the recessed dial, analog hands, and central digital time and date. Use watch-local time and respect the device's 12/24-hour setting.

Port the drawing to Connect IQ graphics in stages so the first sideload can validate wrist legibility and spacing. A full port would also require device data and configuration work before that first check. Complications, graphs, and finish selection are outside this build.
